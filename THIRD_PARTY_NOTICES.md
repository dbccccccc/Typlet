## Typst

- Source: https://github.com/typst/typst, version 0.15.1 (commit `9dfd3a08500b7896045f907433cf7b4b02434fad`)
- Copyright: The Typst Project Developers
- License: Apache License 2.0, in `LICENSES/Apache-2.0.txt`
- Used in Typlet:
  - **Ported source code.** Files under `src/` whose header says "Ported from Typst" are TypeScript translations of Typst's Rust source, modified for Typlet. Each header names its upstream file, and `docs/UPSTREAM.md` lists all of them.
  - **Styles.** `fonts/typlet.css` carries Typst's styles for MathML, from `crates/typst-html/src/mathml.rs`, through their port in `src/mathml/mathml.ts`.
  - **Generated data.** `src/generated/names.ts` lists the names in Typst's global scope, generated by running Typst (see `oracle/`).
  - **Test fixtures.** `test/fixtures/` holds output generated by running Typst (see `oracle/`).
  - **Test corpus.** `test/corpus/typst-docs.jsonl` holds the math examples from the documentation comments in Typst's `typst-library/src/math` source.
- Typst's own NOTICE file lists third-party components. These apply to code Typlet ports:
  - Typst's default color set, adapted from colors.css (https://clrs.cc/), MIT License. It defines Typlet's named colors.
  - Typst's `SyntaxSet`, based on rust-analyzer's `TokenSet` (https://github.com/rust-lang/rust-analyzer), MIT or Apache-2.0. It is the basis of the syntax sets in Typlet's parser.

## New Computer Modern

- Author: Antonis Tsolomitis
- Source: New Computer Modern Math Book and Bold, version 4.0, as bundled with Typst 0.15.1 in typst-assets
- License: GUST Font License, version 1.0 (based on the LaTeX Project Public License 1.3c), in `fonts/GUST-FONT-LICENSE.txt`
- Used in Typlet:
  - **Derived fonts.** The fonts under `fonts/` are subset, split and converted from New Computer Modern Math Book and Bold. As the license requests, they are renamed "Typlet NewCM Math", and `fonts/MANIFEST-typlet-newcm-math.txt` lists the files and the changes.
  - **Metrics.** `src/generated/metrics.ts` and `src/generated/metrics-extended.ts` hold glyph metrics and MATH table data read from New Computer Modern Math Book, and `src/generated/metrics-bold.ts` the metrics of its Bold font's Latin characters.

## KaTeX (development only)

- Source: https://github.com/KaTeX/KaTeX, MIT License
- Used in Typlet: a development dependency of the benchmarks in `bench/` and of the documentation site's comparison page. It is not part of the published package. The site's build (`tools/site/build.mjs`) copies KaTeX's script, stylesheet and fonts from its npm package into `site/katex/`, unmodified and with its license, so that the page can render the same formulas with both. The LaTeX formulas in `test/corpus/paired.jsonl` are Typlet's own, written for KaTeX.
- The integrations follow the APIs of KaTeX's auto-render and copy-tex modules and of rehype-katex (https://github.com/remarkjs/remark-math, MIT License), so pages can switch from KaTeX easily: `contrib/auto-render.ts`, `contrib/copy-typst.ts` and `packages/rehype-typlet/`. They are written for Typlet and share no code with them.
